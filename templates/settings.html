Artwork Cover images for movies, series and games {% if tmdb.configured %}TMDB key set{% else %}Off{% endif %}

When you click Download, Direkt reads the title from the file name and shows matching artwork in the confirmation menu: from TMDB for movies and TV series (needs the key below), from Steam for video games (no key). Only the parsed title and year are sent. Images are cached in the data directory and served by Direkt, so your browser never contacts TMDB or Steam. Files without a confident match keep their file-type tile.

Create a free API key in your TMDB account under Settings → API, then paste the API key or the API read access token here.

Media library Where movies and series are organized for Jellyfin and Plex {{ library.summary }}

When a movie or an episode finishes downloading, Direkt renames it and moves it into the folder below, the way Jellyfin and Plex expect, so a library scan picks it up without any help. It uses the type and title from the confirmation menu, and the file name for the season and episode. Existing files are never replaced. Games, music, software and archives stay in the download folder.
